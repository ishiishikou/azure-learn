# AZ-900 Coverage Matrix

検証日: 2026-09-24

正本: Microsoft Learn「Study guide for Exam AZ-900: Microsoft Azure Fundamentals」2026-07-20版。

公式Study Guide: https://learn.microsoft.com/en-us/credentials/certifications/resources/study-guides/az-900

## Domain 1: Describe cloud concepts (25–30%)

| Skill group | Sub-skill coverage |
| --- | --- |
| Describe cloud computing | cloud computing / shared responsibility / public-private-hybrid cloud / cloud model use cases / consumption-based model / cloud pricing models / serverless |
| Describe the benefits of using cloud services | high availability / scalability / reliability / predictability / security / governance / manageability |
| Describe cloud service types | IaaS / PaaS / SaaS / service-type use cases |

## Domain 2: Describe Azure architecture and services (35–40%)

| Skill group | Sub-skill coverage |
| --- | --- |
| Describe the core architectural components of Azure | regions / region pairs / sovereign regions / availability zones / datacenters / resources / resource groups / subscriptions / management groups / hierarchy |
| Describe Azure compute and networking services | containers / VMs / Functions / VM Scale Sets / availability sets / Azure Virtual Desktop / VM resources / application hosting / virtual networks / subnets / peering / Azure DNS / VPN Gateway / ExpressRoute / public-private endpoints |
| Describe Azure storage services | Storage service comparison / tiers / redundancy / storage accounts and types / AzCopy / Storage Explorer / File Sync / Azure Migrate / Data Box |
| Describe Azure identity, access, and security | Entra ID / Entra Domain Services / SSO / MFA / passwordless / external identities / Conditional Access / RBAC / Zero Trust / defense in depth / Defender for Cloud |

## Domain 3: Describe Azure management and governance (30–35%)

| Skill group | Sub-skill coverage |
| --- | --- |
| Describe cost management in Azure | cost factors / Pricing Calculator / Cost Management capabilities / tags |
| Describe features and tools in Azure for governance and compliance | Microsoft Purview / Azure Policy / resource locks |
| Describe features and tools for managing and deploying Azure resources | Azure portal / Cloud Shell / Azure CLI / Azure PowerShell / Azure Arc / IaC / ARM / ARM templates |
| Describe monitoring tools in Azure | Azure Advisor / Service Health / Azure Monitor / Log Analytics / Monitor alerts / Application Insights |
